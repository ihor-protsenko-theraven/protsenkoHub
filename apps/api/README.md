# API

NestJS 11 + Prisma 6 API. Налаштування, запуск і production-вимоги описані в
[кореневому README](../../README.md).

Поточна схема бази даних використовує PostgreSQL (локально через Docker, у продакшені — Neon). Демонстраційний seed призначений
тільки для локальної розробки й не запускається при `NODE_ENV=production`.
